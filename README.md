# 相撲 決まり手マッチングクイズ

相撲の決まり手（40種以上）の説明文と技名を対応させるマッチングクイズアプリ。技名→説明、説明→技名、カテゴリー問題の3モードで楽しく決まり手を学べる。各回答後に技の詳細説明と有名力士エピソードを表示し、カテゴリー別正答率も記録される。

## 機能
- 40種以上の決まり手データベース（押し/寄り・投げ・掛け・引き・捻り・特殊）
- 3つのクイズモード（技名→説明、説明→技名、カテゴリー問題）
- 各回答後に技の詳細説明＋有名力士情報を表示
- カテゴリー別正答率の統計表示
- ストリークカウンター（連続正解記録）
- ベストスコア・最長ストリークのlocalStorage保存
